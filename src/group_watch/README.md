# 后端结构（src 布局）

```text
src/group_watch/
├── ds/                     # DeepSeek 调用、配额与请求审计
├── evidence/               # 人工登记、档案、资料、证据与档案库
├── monitoring/             # 消息监控、规则、业务库、反馈与接口
├── query/                  # 查询服务、工作进程与接口
├── sources/                # QQ 等消息来源及群/成员目录
├── utils/                  # 图片、文件、SQLite、时间等共用能力
├── web/                    # Web 接口、认证、安全设置与维护路由
├── app.py                  # 组装服务、依赖、路由和启动/关闭生命周期
├── launcher.py             # 服务进程管理
└── settings.py             # 配置加载与校验
```

## 模块边界

- `monitoring/` 处理实时消息、候选线索、规则、反馈和业务状态；`sources/` 将不同平台接入统一群聊流程。
- `sources/members.py` 在业务库保存 QQ 成员资料，启动后及每隔 2 小时采集，只新增或更新。查库 → 单成员 OneBot 查询 → 原昵称接口回退。
- `web/` 集中处理认证、安全、设置和维护接口；各业务目录也负责自己的路由。
- `evidence/` 管理人工登记的事件档案、成员资料、规则、操作记录及图片资源，使用独立档案库。
- `query/` 提供工作台查询能力；`ds/` 封装模型调用、配额和请求日志，供复核、登记与查询流程使用。
